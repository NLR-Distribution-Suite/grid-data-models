gdm.systems.substation.topology module#

Substation facility and electrical topology models.

Station topology follows the bus-branch design used by DistributionSystem. Electrical nodes are BusbarSection instances (a DistributionBus subclass) and primary equipment references the nodes it connects directly, instead of using string IDs and terminal/connectivity-node indirection.
