gdm.systems.substation.builder module#

Test support for constructing detailed distribution substations.

SubstationBuilder assembles a SubstationSystem while keeping the bus-branch component references, bays, and administrative objects consistent. It is the supported way to construct a detailed station instead of wiring components together by hand. This helper is intentionally kept outside the production package.

  • description (str | None) – Optional system description.
